# M.S.F — مساعد المبيعات (مشروع أندرويد)

هذا مشروع Android بسيط يضم واجهة M.S.F داخل تطبيق Android مستقل (WebView)، مع:
- واجهة عربية سوداء وذهبية.
- حفظ المنتجات محليًا على الجهاز عبر localStorage.
- اختيار صور متعددة من الهاتف.
- بحث صوتي عربي عبر خدمة التعرف على الكلام المتاحة في أندرويد.
- نسخ احتياطي واستعادة JSON من داخل الواجهة.

## بناء APK
تم تضمين GitHub Actions workflow لبناء APK تلقائيًا:
1. ارفع محتويات هذا المشروع إلى مستودع GitHub جديد أو استبدل محتويات مستودع مصدر مخصص به.
2. افتح تبويب Actions.
3. افتح `Build M.S.F APK` وانتظر انتهاء التشغيل بنجاح.
4. من صفحة التشغيل، نزّل artifact باسم `MSF-Sales-Assistant-APK`. يحتوي على `app-debug.apk`.
5. انقل APK إلى هاتف Android وثبّته بعد السماح بالتثبيت من هذا المصدر.

## ملاحظات
- هذا APK تجريبي غير موقّع للنشر في المتاجر؛ مناسب للاختبار والتثبيت اليدوي.
- بيانات المنتجات والصور تُحفظ محليًا داخل التطبيق، وهي منفصلة عن بيانات المتصفح/الموقع السابقة. صدّر نسخة JSON من النسخة القديمة واستعدها داخل التطبيق الجديد عند الحاجة.
- التعرف على الكلام يعتمد على خدمة الصوت المتاحة على جهاز Android وقد يحتاج اتصالًا بالإنترنت.
